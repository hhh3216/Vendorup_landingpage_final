## 1. 토스에서 가져온 것 / 버린 것

레퍼런스 캡처는 `디자인레퍼런스/` 폴더 5장 (`02_toss_hero_자산관리.png`, `03_toss_카드섹션_pill헤드라인.png`, `04_toss_다크섹션_주식.png`, `05_toss_payments_B2B.png`, `01_aditya_portfolio_hero.png`).

### ✅ 가져오는 것 (모션 관련)

1. **좌측 고정 + 우측 교체형 스크롤 전환**
   화면 전체가 통째로 넘어가는 풀페이지 전환이 **아니다.** 좌측 컬럼(제목·스텝 리스트)은 `position: sticky`로 붙어 있고, 우측 콘텐츠만 스크롤 진행도에 따라 한 장씩 교체된다. → §4.4 작동원리 섹션의 핵심 구조. 시안에도 이미 `position:sticky;top:120px` 로 좌측 컬럼이 잡혀 있다.

2. **얇은 세로 tick 진행 인디케이터**
   sticky 구간 좌측 끝(또는 스텝 리스트 왼쪽)에 2px 세로 라인. 현재 스텝 구간만 브랜드 바이올렛으로 채워지고, 나머지는 8% 블랙. 채워지는 건 **높이 애니메이션이 아니라 색 전환**(0.3s) — 진행바처럼 보이면 스크롤 하이재킹 인상을 준다.

3. **섹션 배경 통째 전환 (화이트 → 블랙 → 화이트)**
   §2 문제 섹션(`#111317`)과 §10 최종 CTA(브랜드 풀블리드)가 다크 구간. 배경색은 **애니메이션하지 않는다** — 섹션 경계에서 그냥 바뀐다. 대신 다크 구간에 들어갈 때 내부 요소의 진입 애니메이션 거리를 조금 크게(y 24px → 32px) 줘서 "장면이 바뀌었다"는 느낌만 만든다.

4. **헤드라인 내 pill 뱃지 인라인 강조**
   pill은 헤드라인 본문과 **같은 타이밍에** 등장한다. 뱃지만 늦게 튀어나오게 하지 않는다(광고처럼 읽힌다).

5. **카드의 부드러운 그라데이션 + frosted 화이트 레이어**
   호버 시: `translateY(-4px)` + 섀도 확대, 0.24s. 그라데이션 자체를 움직이지 않는다.

6. **카드 우하단 원형 화살표 버튼**
   호버 시 화살표만 x +3px 이동(0.18s). 버튼 원은 고정.

### ❌ 버리는 것

- **스크롤 하이재킹 / 풀페이지 스냅** — 모바일 이탈 요인. 절대 금지.
- **패럴랙스 배경, 마우스 추적 요소, 커서 따라오는 글로우** — B2B 도매 타겟에게 장난스럽게 읽힌다.
- **긴 로딩 인트로, 첫 진입 시 전체 페이드인** — 첫 화면은 즉시 완성된 상태로 보인다.
- **토스의 컬러·폰트·일러스트** — 참고는 레이아웃과 모션 구조에 한정. 컬러는 `#5630E3` / `#03B1D8`.
- **숫자 카운트업 애니메이션** — 확정되지 않은 수치를 쓰지 않는 기획 원칙(카피 원칙 2)과 충돌.

## 2. 전역 모션 토큰

코드에서 이 값만 쓴다. 개별 섹션에서 새 이징이나 새 듀레이션을 발명하지 않는다.

```css
/* 이징 */
--ease-out:    cubic-bezier(.22, 1, .36, 1);    /* 진입: 요소가 들어올 때 */
--ease-inout:  cubic-bezier(.4, 0, .2, 1);      /* 상태 변화: 색·크기·전환 */
--ease-linear: linear;                           /* 스켈레톤 시머, 진행 루프만 */

/* 듀레이션 */
--d-fast:  120ms;   /* 탭·클릭 피드백 */
--d-base:  240ms;   /* 호버, 색 전환, 아코디언 */
--d-enter: 560ms;   /* 스크롤 진입 */
--d-slow:  800ms;   /* 큰 블록(히어로 카드, 가격표) 진입 */

/* 이동 거리 — 이 3개만 사용 */
--y-sm:  12px;   /* 작은 요소: 뱃지, 라벨, 표 한 줄 */
--y-md:  24px;   /* 카드, 문단 */
--y-lg:  32px;   /* 다크 섹션 내부 요소, 섹션 헤드라인 */

/* 스태거 */
--stagger: 70ms;  /* 형제 요소 간 지연. 최대 6개까지만 스태거, 7번째부터는 동시 */
```

**규칙**
- 진입은 항상 `opacity 0→1` + `translateY(+n → 0)`. **scale은 진입에 쓰지 않는다** (예외: 데모 결과 카드, 승인 뱃지 — §6).
- `filter: blur()`를 진입에 쓰지 않는다 (모바일 성능).
- 애니메이션 속성은 `opacity`와 `transform`으로만. `height`, `top`, `margin` 애니메이션 금지 (예외: 아코디언 §4.9, 데모 카드 성장 §6).
- 한 시점에 화면에서 움직이는 것은 **한 종류**. 두 개를 동시에 움직이면 둘 다 안 읽힌다.

## 3. 공통 스크롤 진입 규칙

모든 섹션의 기본 동작. 개별 명세가 없는 요소는 전부 이 규칙을 따른다.

- **트리거:** `IntersectionObserver`, `threshold: 0.15`, `rootMargin: '0px 0px -12% 0px'`
- **동작:** `opacity 0→1`, `translateY(var(--y-md)) → 0`, `var(--d-enter) var(--ease-out)`
- **1회성:** 한 번 등장한 요소는 다시 스크롤해도 재생하지 않는다 (`observer.unobserve` 후 클래스 유지). 위아래로 스크롤할 때 계속 깜빡이면 싸구려로 보인다.
- **스태거 단위:** 섹션 헤드라인 → 리드 문단 → 콘텐츠 블록. 카드 그리드는 카드 단위로 `--stagger`.
- **첫 화면 예외:** 히어로 섹션과 헤더는 진입 애니메이션 **없음.** 페이지 로드 시점에 이미 완성된 상태.

## 4. 섹션별 명세

기획서 섹션 번호 = 시안 순서 기준.

### 4.0 헤더 (sticky)

- 시안: `height:76px; position:sticky; top:0; background:rgba(255,255,255,.86)` + backdrop-blur
- **스크롤 0 → 8px 구간**에서만 `border-bottom` 투명도 `0 → .07`, 섀도 없음 → 있음. `--d-base --ease-inout`
- 스크롤 방향에 따라 헤더를 숨기지 않는다. 항상 붙어 있다.
- 다크 섹션(§2, §10) 위를 지날 때 헤더 색을 반전시키지 않는다. 반투명 화이트 그대로.

### 4.1 Hero

- 좌/우 텍스트·CTA·신뢰 배지: **애니메이션 없음.** 로드 즉시 최종 상태.
- 히어로 영상(우측/배경 카드): §5 참조. 영상은 자동재생·무음·루프.
- CTA 버튼 호버: `translateY(-2px)` + 섀도 확대, `--d-base`. 액티브: `translateY(0)` + `scale(.985)`, `--d-fast`.
- 2차 CTA `30초 만에 어떻게 되는지 보기` → §6 데모 섹션으로 **`scrollTo` 스무스 스크롤**(800ms, `--ease-inout`). 도착 후 데모 입력창에 포커스 링 1회 점등(0.6s 후 소멸) — 자동 재생은 하지 않는다.

### 4.2 문제 섹션 (다크, `#111317`)

- 헤드라인 → 리드 문단 → 3카드. y 거리 `--y-lg`, 스태거 `--stagger`.
- **1번 카드 "끝없는 반복 입력"**: 카드 안 반복 아이콘 4~5개가 좌→우 순차 등장, 각 `90ms` 간격, `opacity 0→1` + `--y-sm`. 마지막 아이콘까지 들어온 뒤 **아무것도 하지 않는다** (반복 루프 금지 — 계속 돌면 문제 묘사가 아니라 로딩으로 읽힌다).
- 2·3번 카드: 공통 규칙만.
- 섹션 마무리 한 줄("문제는 담당자가 아닙니다"): 카드보다 `200ms` 늦게, 단독으로 진입.

### 4.3 해결 섹션 — 강조 스트립 + Before/After 표

- 강조 스트립(그라데이션 카드, "거래처는 지금 하던 대로"): 공통 규칙, `--d-slow`. 그라데이션 애니메이션 없음.
- **Before/After 표 (토스식 순차 채움 — 선택 적용 구간)**
  - 표가 뷰포트 진입하면 **After 컬럼 셀만** 위→아래로 순차 등장. 행당 `100ms` 간격, `opacity 0→1` + `--y-sm`.
  - Before 컬럼은 처음부터 보인다. "지금은 이미 이렇고, 바뀌는 건 오른쪽"이라는 의미가 모션에 실려야 한다.
  - **(그대로)** 표기가 붙은 첫 행은 예외 — Before/After 동시에 보인다. 안 바뀌는 게 요점이므로.
  - 6행이므로 전체 600ms. 이보다 느리면 기다림이 된다.
- 핵심 가치 3줄: 공통 규칙, 스태거.

### 4.4 작동 원리 5스텝 — **토스식 sticky 전환 (이 페이지 모션의 핵심)**

시안 구조: `grid-template-columns: 420px minmax(0,1fr)`, 좌측 `position:sticky; top:120px`.

**구조**
```
<div section>                       height = 100vh * 5 (스텝 수) 확보
  <div left  sticky top:120px>      제목 + 스텝 01~05 리스트 + tick 인디케이터
  <div right>                       스텝별 스크린샷 5장 (스크롤에 따라 교체)
```

**전환 로직**
- 우측을 스텝당 `100vh` 높이의 5개 트랙으로 나눈다. 각 트랙이 뷰포트 중앙선을 지날 때 해당 스텝을 활성화.
- 활성 스텝 인덱스는 `IntersectionObserver`(트랙별, `rootMargin: '-45% 0px -45% 0px'`)로 계산. **스크롤 이벤트 + 계산식보다 IO가 훨씬 안정적이고 가볍다.**
- 우측 스크린샷: 이전 카드 `opacity 1→0` + `translateY(0 → -12px)` / 새 카드 `opacity 0→1` + `translateY(12px → 0)`. 둘 다 `--d-base --ease-inout`, 크로스페이드로 겹치게. 카드는 sticky로 화면 중앙에 고정.
- 좌측 스텝 리스트: 활성 항목 텍스트 `rgba(26,26,26,.4) → #1A1A1A`, 좌측 2px 세로 tick `rgba(16,24,40,.1) → #5630E3`. 색 전환만, `--d-base`. 활성 항목을 확대하거나 움직이지 않는다.
- **스크롤 하이재킹 금지.** 사용자가 빠르게 스크롤하면 스텝이 건너뛰어져도 정상 동작이어야 한다.
- 스텝 04(확인한다) 카드 안 "확신 낮은 항목" 표시: 카드 진입 완료 후 `250ms` 뒤 해당 행 배경이 한 번 점등(`--d-base`)하고 그대로 유지. 반복 점멸 금지.

**⚠️ 준비물:** 제품 스크린샷 5장 (기획서 체크리스트 미확정 항목). 미수령 시 시안의 목업 카드로 구현하고 이미지 교체 지점만 주석 표시.

### 4.5 주문 접수 방식 (방식 1 / 방식 2 비교)

- 두 카드 **동시에** 진입. 스태거를 주면 한쪽이 주력으로 읽힌다 — 기획 확정사항(둘 다 동등)에 위배.
- 각 카드 내부 플로우차트 4~5단계: 카드 진입 후 좌→우 순차 등장, `80ms` 간격. **화살표가 요소보다 먼저 나오지 않게** (노드 → 화살표 → 노드 순서).
- 두 카드의 플로우 애니메이션은 **동시에 시작**하되, 단계 수가 다르면 각자 자기 속도로 끝난다.
- 호버: 카드 `translateY(-4px)` + 테두리 색 진해짐, `--d-base`. 선택 상태(클릭) 없음 — 정보 카드다.

### 4.6 라이브 데모 → §6 참조 (별도 절)

### 4.7 로드맵 타임라인

- 가로 타임라인. 진입 시 **좌측 "지금 이용 가능" 구간의 채워진 라인이 좌→우로 그려진다.** `transform: scaleX(0 → 1)`, `transform-origin: left`, `--d-slow --ease-out`. (`width` 애니메이션 금지)
- 채워진 구간이 끝나는 지점에서 멈춘다. 우측 "3~6개월 내" 구간은 점선 또는 미채움 상태로 처음부터 보인다.
- 항목 카드 5개(재고관리·시세·기사추적·AI배송·사진인식): 라인이 다 그려진 후 스태거로 진입.
- `신규` 뱃지(AI 배송): 해당 카드와 동시 등장. 별도 강조 모션 없음.

### 4.8 가격표

- 3플랜 카드: **가운데 AI ORDER부터** 진입 → 좌우가 `--stagger` 뒤에 따라온다. 주력 플랜에 시선이 먼저 가야 한다.
- AI ORDER 카드는 `--d-slow`, 나머지 `--d-enter`.
- `추천` 뱃지: 카드 진입 완료 시점에 함께. 뱃지 단독 팝인 금지.
- 정가 취소선: 처음부터 취소선 상태로 보인다. 선이 그려지는 애니메이션은 하지 않는다 (할인 광고 클리셰).
- 가치 스택 체크리스트: 항목당 `60ms` 스태거. 체크 아이콘 드로잉 애니메이션 없음.
- 긴급성 스트립("10개사 마감 시 종료"): 공통 규칙. **깜빡임·펄스·카운트다운 금지.**

### 4.9 FAQ 아코디언

- 첫 항목만 펼친 상태로 시작. 진입 애니메이션은 아코디언 전체 블록 단위로 1회.
- 펼침/접힘: `grid-template-rows: 0fr → 1fr` (또는 `max-height` + `scrollHeight` 측정), `--d-base --ease-inout`. 내용 `opacity`는 `--d-fast` 지연 없이 함께.
- 화살표/+ 아이콘: `rotate(0 → 180deg)` 또는 `rotate(0 → 45deg)`, `--d-base`.
- **아코디언은 배타적이지 않다** — 여러 개 동시 펼침 허용. 하나 열 때 다른 걸 접으면 비교 읽기가 안 된다.
- 펼칠 때 자동 스크롤 하지 않는다 (`scrollIntoView` 사용 금지).

### 4.10 최종 CTA (브랜드 풀블리드)

- 헤드라인 → 서브 → 폼. y 거리 `--y-lg`, 스태거.
- 폼 필드 5개: 개별 스태거 없이 폼 블록 단위로 한 번에.
- 필드 포커스: 테두리 색 + 2px 링, `--d-fast`. 라벨 플로팅 애니메이션 없음(라벨 상단 고정형).
- 제출 버튼: 클릭 시 `scale(.985)` `--d-fast` → 로딩 스피너(회전 `linear` 900ms 루프) → 완료 상태 텍스트 교체. 성공 시 폼 블록이 `opacity` 크로스페이드로 감사 메시지로 교체(`--d-base`). 종이비행기·컨페티 금지.
- 유효성 오류: 필드 테두리 색 전환만. **shake 애니메이션 금지.**

### 4.11 푸터

- 진입 애니메이션 **없음.** 푸터는 스크롤 끝이므로 등장 연출이 의미 없다.
- 카이톤 로고: 정적. 그라데이션 애니메이션 금지.
- 링크 호버: 밑줄 `scaleX(0→1)` `transform-origin:left` `--d-fast`, 또는 색 전환만.

- `<video autoplay muted loop playsinline>` — `muted`와 `playsinline` 없으면 모바일에서 재생되지 않는다.
- `poster`는 **프레임 01**(phone-idle)로. 로딩 중에도 레이아웃이 흔들리지 않게 `aspect-ratio: 16/9` 고정.
- 영상 하단 432px 위에 랜딩 그라데이션(하단→상단, 불투명→투명) + 헤드라인 오버레이. **오버레이는 영상보다 위 레이어에 항상 고정** — 페이드인 하지 않는다.
- `prefers-reduced-motion: reduce`일 때: 영상 자동재생 정지, **프레임 05b(approve) 정지 이미지로 대체.** 스토리의 결론이 담긴 프레임이므로.
- 모바일: 세로 크롭 대신 **가운데 폰 영역만 보이도록 `object-fit: cover; object-position: center top`**. 파일 용량 때문에 별도 모바일 버전을 만들 경우 9:16 리컷 필요 — 그때는 06 split 샷을 제외한다(가로 전용 구도).

## 6. 라이브 데모 — 유일한 입력 기반 인터랙션

스크롤 트리거가 아니라 **사용자 입력**으로 시작한다. 다른 섹션과 로직을 공유하지 않는다.

**확정사항 (기획서 §6)**
- 실제 AI 연동 없음. **사전 정의된 예시 문장 기반 시뮬레이션.** 어뷰징·비용·응답지연 리스크 제거.
- 탭 1 = 방식 1(거래처가 Vendor-UP 채널로 전송) / 탭 2 = 방식 2(받은 주문 복붙)
- 현재 텍스트 입력만. 사진·캡처 인식은 준비 중 안내 문구 유지.
- ⚠️ **미확정:** (A) 자유 입력 허용 + 실패 시 예시 유도 / (B) 예시 클릭 전용 → 구현 착수 전 확정 필요. 미확정 시 **(A)로 구현하고 실패 폴백을 반드시 붙인다.**

### 6.1 상태 머신

```
idle ──(전송/예시 클릭)──▶ sending ──▶ extracting ──▶ matching ──▶ pending ──(승인 클릭)──▶ done
  ▲                                                                                          │
  └──────────────────────────(다시 해보기)──────────────────────────────────────────────────┘
```

시안에는 이 중 `입력 전 / 처리 중 / 확인 대기 / 등록 완료` 4개 정지 화면이 확정되어 있다 (탭1·탭2 각 4장, 총 8장).

### 6.2 상태별 모션

| 상태 | 지속 | 모션 |
| --- | --- | --- |
| `idle` | — | 입력창 커서 블링크(기본값). placeholder 타이핑 애니메이션 **금지**. 예시 칩 호버 `translateY(-2px)` |
| `sending` | 300ms | 탭1: 말풍선이 입력창에서 채팅 영역으로 `opacity 0→1` + `scale .96→1` + `--y-sm`, `--ease-out`. 탭2: 입력 텍스트가 우측 처리 패널 상단 "원문" 영역으로 크로스페이드. 입력창은 즉시 비워짐 |
| `extracting` | 900ms | 원문 텍스트 안에서 **품목·수량 토큰에 하이라이트 배경이 좌→우 순차 점등** (토큰당 120ms). 우측 결과 영역은 스켈레톤 4행 시머(`linear`, 1.2s 루프, 행당 0.08s 스태거) |
| `matching` | 700ms | 스켈레톤이 행 단위로 실제 값으로 교체, **행당 120ms 간격 위→아래.** 품목코드 칩은 **마지막에 전체 동시 점등** + 0.3s 바이올렛 글로우 1회 (히어로 영상 05a와 동일한 연출 — 의도된 반복) |
| `pending` | 유지 | `확인 대기` 상태 뱃지 팝인(`scale .9→1`, 200ms). 카드가 아래로 성장하며 승인 바 노출 — **상단 엣지 고정.** `승인` 버튼 글로우 펄스 **1회만**(0.6s) |
| `done` | 유지 | `등록 완료` 상태로 텍스트·색 전환(`--d-base`). 체크 아이콘 팝인. `다시 해보기` 링크 페이드인. 컨페티·성공음 금지 |

**총 처리 시간 약 1.9초.** 실제 AI가 아니므로 더 길게 끌 이유가 없고, 더 짧으면 "처리했다"는 인상이 남지 않는다.

### 6.3 예외 처리

- **자유 입력 실패(사전 정의 예시와 매칭 안 됨):** 처리 애니메이션을 끝까지 돌리지 않는다. `extracting` 300ms 후 중단 → 입력창 아래에 안내 한 줄 + 예시 칩 3개 하이라이트(1회 점등, `--d-base`). 에러 색상(레드) 사용 금지 — 실패가 아니라 유도다.
- **빈 입력 전송:** 아무 일도 일어나지 않는다. 흔들기·경고 금지.
- **처리 중 재전송:** 진행 중 상태를 취소하고 새로 시작. 큐에 쌓지 않는다.
- **탭 전환:** 각 탭의 상태는 독립 유지. 탭1을 `done`까지 본 뒤 탭2로 갔다 돌아오면 `done` 상태 그대로. 탭 전환 자체는 크로스페이드 `--d-base`, 슬라이드 금지.

## 8. 접근성 · 성능 · 금지사항

### 8.1 접근성

- **`prefers-reduced-motion: reduce`:** 모든 진입 애니메이션·스태거·시머 제거. 요소는 최종 상태로 즉시 표시. 히어로 영상은 05b 정지 이미지로 교체. sticky 스텝 전환은 유지하되 크로스페이드 없이 즉시 교체.
- **애니메이션 없이도 모든 내용이 읽혀야 한다.** JS 실패 시 `opacity: 0`으로 남아 콘텐츠가 사라지는 구현 금지 — 기본 CSS는 최종 상태로 쓰고, JS가 붙었을 때만 초기 상태를 적용한다(`.js-anim` 루트 클래스 방식).
- 데모 상태 변화는 `aria-live="polite"`로 알린다.
- 아코디언은 `<button aria-expanded>` + `<div role="region">`.
- 키보드 포커스 링을 모션으로 감추지 않는다.

### 8.2 성능

- `opacity` / `transform`만 애니메이션. `will-change`는 애니메이션 직전에만 부여하고 완료 후 제거.
- `IntersectionObserver`는 발동 후 `unobserve`. 스크롤 이벤트 리스너는 헤더 섀도 하나만(`passive: true` + rAF 스로틀).
- 스켈레톤 시머는 CSS `@keyframes` 기반. JS 타이머로 프레임 갱신 금지.
- 히어로 영상은 `preload="metadata"`. 뷰포트 밖으로 나가면 `pause()` (IO 기반).
- LCP 요소(히어로 헤드라인)에 애니메이션을 걸지 않는다.

### 8.3 금지사항 (요약)

1. 스크롤 하이재킹 / 풀페이지 스냅
2. 패럴랙스, 커서 추적, 마우스 기반 글로우
3. 진입 애니메이션 반복 재생 (스크롤 왕복 시 깜빡임)
4. 숫자 카운트업, 가짜 카운터, 남은 자리 애니메이션
5. shake, bounce, 컨페티, 종이비행기, 이모지 모션
6. `승인` 버튼 2회 이상 펄스 / 점멸
7. `height` · `width` · `top` · `margin` 애니메이션 (§4.9, §6 예외)
8. placeholder 타이핑 효과, 카톡 말풍선 타이핑 효과
9. 첫 진입 전체 페이드인 / 로딩 인트로
10. `scrollIntoView` (스무스 스크롤은 `scrollTo` 사용)
11. 다크 섹션 진입 시 배경색 트랜지션
12. 동시에 두 곳 이상 움직이기
